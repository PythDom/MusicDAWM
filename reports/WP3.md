# WP3 report: Drum Studio

*2026-10-23. MusicDAWM 0.1.0.*

## What was built

- **Groove library** (`share/drumstudio/grooves`, CC0). 12 styles × 7 parts × 4 complexities = 336 General MIDI drum files, generated by rules in `tools/drumstudio/make_grooves.py`: rock, pop, ballad, blues shuffle, funk, country, reggae, bossa nova, jazz swing, half-time, 6/8, punk. Ardour's bundled MIDI rhythms are not used (their licence was not confirmed).
- **Bundled kit** (D-011, D-025). The AVL Drumkits (Black Pearl, Red Zeppelin, Blonde Bop, Buskman's Holiday), played by the x42-avldrums LV2 plugin. `ci/avldrums-build.sh` builds it from a pinned commit into the Windows package with its licence and the kits' readme. Licences were read in the source (THIRD_PARTY.md).
- **Engine** (`libs/ardour/drum_studio.cc`):
  - *Create drum track:* a MIDI track with the kit and all 28 cells as trigger slots (D-018), hidden from the Cue page.
  - *Perform mode:* switches at the next beat, bar or two bars; a fill returns to the previous part after one bar; the ending plays once. Each switch is sent as a cue one beat ahead (D-021).
  - *Recording:* Rec Cues records the switches as cue markers, with a new opt-in session option to snap them to the beat. A part started while stopped is recorded too.
  - *Flatten:* turns the markers into MIDI regions, each with its own notes, named after style, part and complexity. It then stops the slots from also following the cues, and extends the session range.
- **Drum Studio panel** (`gtk2_ardour/drum_studio_panel.cc`), a page of the Editor sidebar (D-019), opened from Window → Drum Studio:
  - style and kit pickers, Create Drum Track / Load Style;
  - the 7 × 4 grid: click to audition or switch; the playing cell is red and the next one outlined;
  - Switch at (beat, bar, 2 bars), Keys (perform keys I V P C B F E and 1–4 behind a switch, D-020), Record, Stop, Flatten, Play Cues.
- **Fixes found by testing in the GUI:**
  - Flattened drums were silent, because a track with clips skips its regions in automatic monitoring. Drum tracks now monitor input + disk (D-022).
  - 6/8 grooves were imported 8 beats long. MIDI import now keeps an explicit file length (D-023, `libs/ardour/import.cc`).
  - Creating a 6/8 drum track sets the song to 6/8 (D-024).
  - New drum tracks start at −6 dB, because the kit clipped on accented crashes.
- **Tools:** `musicdawm9-drum_studio_test` (below) and `musicdawm9-drum_studio_demo <dir> <style>`, which writes a demo song in one style for listening.

## Known issues

- **Switch timing depends on the GUI.** Switches are sent from the GUI's 40 ms timer, one beat ahead. If the program freezes for longer than a beat just before a switch, that switch lands one beat late (seen once under Xvfb while a screenshot tool held the display). The marker can be dragged. Moving the scheduling into the audio thread would remove this; not done, to keep Ardour's cue code unchanged.
- **Stock Ardour compatibility** of a session with a drum track is expected (additive XML, a session option stock Ardour ignores, 28 slots instead of 16) but **not tested**.
- **Reloading a second session in the same process** sometimes hung in `Graph::drop_threads` during testing. The test reopens the session in a second process instead. It was not seen in the GUI; to watch for when switching sessions on Windows.
- `musicdawm9-export` crashes on a session without a master bus (a pre-existing Ardour behaviour of the command-line tool; sessions made in the GUI have one).
- The plugin's own GUI is not bundled (D-025); kit settings use Ardour's generic plugin controls.
- The perform keys only work while the Drum Studio page is shown and Keys is on (D-020).
