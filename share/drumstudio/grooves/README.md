# Drum Studio groove library

336 drum grooves: 12 styles x 7 song parts (intro, verse, pre-chorus, chorus,
bridge, fill, ending) x 4 complexity levels.

- **Licence:** CC0 1.0 (public domain dedication). Use them in anything,
  no credit needed.
- **Made by rules**, not copied from anywhere: `tools/drumstudio/make_grooves.py`
  generates every file here, and `tools/drumstudio/test_grooves.py` checks that
  the committed files match the generator. Do not edit them by hand;
  change the generator and regenerate.
- **Drum map:** General MIDI notes that the bundled AVL kit plays the same way
  (see the generator's header for the list).
- `index.xml` (read by MusicDAWM) and `index.json` describe all files.
