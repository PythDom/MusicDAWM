# Third-party components and licences

Every bundled or linked component is listed here with its licence and how that licence was verified.
"Verified" means the licence file in the source tree was read. A licence is never inferred from a website summary.

| Component | Version | Licence | Use | Verified | Notes |
|---|---|---|---|---|---|
| Ardour | 9.8 (`22ed8656`), full history merged into this repository | GPLv2 or later | Base of the fork | `COPYING`, file headers | Some files under `libs/` carry their own (compatible) licences, as Ardour lists them. |
| ARA SDK (`ARA_API`, `ARA_Library`) | 2.3.0 | Apache-2.0 | WP9 (ARA2 hosting) | `ARA_API/LICENSE.txt`, `ARA_Library/LICENSE.txt` | **Compatible with GPLv3 only, not GPLv2.** See `DECISIONS.md` D-005. Not integrated yet. |

Before any release (WP1), list each with its licence and ship the licence texts. |
| CLAP SDK | – | MIT | WP8 | not yet | |
